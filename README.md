# Azeroth Food Tour Guide

A small web app for browsing Warcraft food-related places in Azeroth.

The idea is to build a curated fan guide focused on things like:

- inns
- taverns
- food vendors
- cooking-relevant zones
- themed travel routes

The original incarnation of this was much bigger, basically a "Warcraft travel platform" a la Expedia, intended as a fullstack + Devops demo. That is no longer the goal.

Now the aim is a small, coherent content-driven app that is actually buildable by one person and fun to make.

## What it is

WoW has a lot of food, tavern, inn, and travel-flavored worldbuilding, but it is scattered across memory, wikis, and general-purpose databases. This project is meant to collect that material into one place that is fun to browse.

The tone is meant to be closer to a curated guide than a full database.
